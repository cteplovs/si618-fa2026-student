# homework/

One directory per assignment, laid out like this:

```
hwNN/
  README.md    the spec you read
  RUBRIC.md    the rubric we grade against, published in advance
  starter.py   a marimo notebook with the sections stubbed out
```

Specs are markdown documents rather than notebooks, and submissions are a marimo `.py`
along with its exported `.html`. We don't accept `.ipynb` files anywhere in this course.
