# inclass/

One marimo notebook per topic. Most run across two 80-minute sessions, and are split
partway through at a marker that looks like this:

```
## ⏸️ END OF SESSION 1 — pick up here next class
```

You work through the first session's half, stop at the marker, and carry on from there
in the next class. The notebook is submitted once, at the end of the second session.

Open any of them with:

```bash
uvx marimo edit --sandbox inclass/SI_618_01_Introduction.py
```

If none of that is familiar yet, [docs/setup.md](../docs/setup.md) is the place to start.
